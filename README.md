# Projeto Web: Mosteiro Zen Morro da Vargem

Este repositório contém o projeto de página web desenvolvido para a disciplina de **Ferramentas de Desenvolvimento Web** do curso de **Análise e Desenvolvimento de Sistemas**.

O objetivo do projeto é divulgar um ponto turístico capixaba, apresentando informações detalhadas, imagens reais, vídeos integrados e recursos interativos de navegação.

---

## 🌎 Estrutura do Projeto

### 1. HTML5 (Estrutura Semântica)
* **Objetivo:** Garantir acessibilidade, boa organização visual e otimização para SEO.
* **Conteúdo:** 
  * Estruturação semântica com `<header>`, `<main>`, `<section>` e `<footer>`.
  * Inclusão de vídeos (`<iframe>`), imagens responsivas, listas informativas e links para sites externos.

### 2. CSS3 (Estilização e Design Capixaba)
* **Objetivo:** Criar um layout atraente, responsivo e personalizado.
* **Recursos Utilizados:**
  * **Paleta de cores oficial do Espírito Santo:** Azul Celeste (`#3EA4D7`), Rosa (`#E85D88`) e Branco.
  * Ajustes de margens, paddings, bordas arredondadas e sombras para um acabamento visual moderno.
  * Efeitos de hover nas imagens e botões de ação interativos.

### 3. Funcionalidades Interativas
* **Objetivo:** Enriquecer a experiência do usuário na página.
* **Recursos Implementados:**
  * **Carrossel Interativo:** Navegação com botões tipo "passa-lado" exibindo outros pontos turísticos do ES (Guarapari, Pedra Azul e Convento da Penha).
  * **Vídeo Integrado:** Reportagem sobre o Mosteiro Zen integrada à página.
  * **Informações Práticas:** Horários de visitação e endereço oficial do local.
